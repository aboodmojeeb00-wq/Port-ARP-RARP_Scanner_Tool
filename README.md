# Port & ARP-RARP Scanner Tool

**الإصدار:** 1.0.0  
**اللغة:** Pure Python (بدون أي مكتبات خارجية)  
**المادة:** لغة البرمجة للأمن السيبراني

---

## 1. المشكلة

في مجال الأمن السيبراني، يحتاج المحلل أو المختبر الأمني إلى أدوات بسيطة وموثوقة لـ:

- اكتشاف المنافذ المفتوحة على الأجهزة (Port Scanning)
- معرفة الأجهزة المتصلة بالشبكة المحلية عبر بروتوكول ARP
- إجراء بحث عكسي من عنوان MAC إلى عنوان IP (مفهوم RARP)
- تحويل اسم النطاق (Domain) إلى عنوان IP والعكس (IP → Domain)

---

## 2. فكرة المشروع

بناء أداة سطر أوامر (مع واجهة تفاعلية + واجهة رسومية) بلغة بايثون النقية تقوم بالوظائف التالية:

1. **Port Scanner**: مسح منافذ TCP على هدف محدد باستخدام مكتبة `socket`.
2. **ARP Scanner / Viewer**: عرض جدول ARP الحالي أو إجراء مسح نشط للشبكة المحلية (Ping ثم قراءة ARP).
3. **RARP Lookup** (يدعم ثلاثة أنواع من الإدخال):
   - **MAC → IP**: بحث عكسي من جدول ARP (RARP)
   - **Domain → IP**: تحويل النطاق إلى IP عبر DNS
   - **IP → Domain**: تحويل الـ IP إلى اسم النطاق عبر Reverse DNS

الأداة تعمل على نظامي **Windows** و **Linux** (بما فيها Kali).

### الطريقة الأولى: الواجهة التفاعلية (CLI)

```bash
python scanner.py
```

```
=======================================================
   Port & ARP-RARP Scanner Tool
   Version 1.0.0
=======================================================

  Select a function:

  [1]  Port Scanner
  [2]  ARP Table / Network Scan
  [3]  RARP Lookup (MAC / Domain / IP)

  [h]  Help
  [v]  Version
  [c]  Config
  [l]  Log-level
  [0]  Exit
```

| المفتاح | الوظيفة |
|---------|---------|
| `1` | مسح المنافذ |
| `2` | عرض / مسح ARP |
| `3` | **RARP Lookup**: MAC→IP أو Domain→IP أو IP→Domain |
| `h` | المساعدة |
| `v` | رقم الإصدار |
| `c` | تحميل ملف إعدادات |
| `l` | تغيير مستوى التسجيل |
| `0` | خروج |

داخل أي وظيفة: `h` للمساعدة | `b` للرجوع

### الطريقة الثالثة: أوامر سطر الأوامر (CLI)

```bash
# المساعدة والإصدار
python scanner.py --help
python scanner.py --version

# مسح المنافذ
python scanner.py port --target 192.168.1.1 --ports 80,443,22
python scanner.py port -t 192.168.1.1 -p 1-1000 --timeout 2

# ARP
python scanner.py arp
python scanner.py arp --scan
python scanner.py arp --scan --network 192.168.1.0/24

# RARP Lookup
python scanner.py rarp --mac 00:11:22:33:44:55
python scanner.py rarp --host google.com
python scanner.py rarp google.com
python scanner.py rarp 8.8.8.8

# مع إعدادات ومستوى تسجيل
python scanner.py --config config.json --log-level DEBUG port -t 192.168.1.1 -p 80
```

## 6. ملاحظات تقنية

- **Pure Python**: مكتبات قياسية فقط  
  (`socket`, `subprocess`, `argparse`, `ipaddress`, `concurrent.futures`, `logging`, `json`, `platform`, `tkinter`)
- **معالجة الأخطاء**: رسائل واضحة لأي إدخال غلط
- **التوافق**: Windows و Linux/Kali
- **DNS**: Forward عبر `socket.getaddrinfo` | Reverse عبر `socket.gethostbyaddr`
- **ARP على Linux**: قراءة من `/proc/net/arp` و `ip neigh` و `arp`
